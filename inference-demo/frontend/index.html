Direct provider keys
Add your own OpenAI or Google Gemini API key. The key is stored in AgentCore Identity (API key mode) and a custom inference target is created on the same Gateway — so these models are invoked through the AgentCore Gateway with your key (not via bedrock-mantle). On save, each model is validated by a real test call; only models the key can actually use are added to the Inference and Evaluation pickers. Remove a key to hide them again.
The key is sent once to validate + store it in AgentCore Identity; it is never returned to the browser afterwards. It is transmitted only over the CloudFront + Cognito protected path.
